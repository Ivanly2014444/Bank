# Виджет банковских операций

## Модуль `widget.py`

Программа для маскирования номеров карт и счетов. Проект написан на Python с использованием современных инструментов статического анализа и форматирования кода.

## 📝 Описание функций
* `get_mask_card_number(card_number)` — принимает 16-значный номер карты и возвращает его в замаскированном формате: `XXXX XX** **** XXXX`.
* `get_mask_account(account_number)` — принимает номер счета и возвращает последние 4 цифры с маской: `**XXXX`.

## Модуль `processing`

Модуль предназначен для базовой фильтрации и сортировки списков данных (например, банковских операций или логов).

## Описание функций

* *`filter_by_state`* — фильтрует исходный список словарей по заданному статусу (ключ `state`). По умолчанию отбирает элементы со значением `EXECUTED`.


* *`sort_by_date`* — сортирует элементы по дате (ключ `date`). Поддерживает сортировку как по убыванию, так и по возрастанию.

## Модуль `generator`

роект содержит набор утилит для работы с банковскими транзакциями и генерации номеров пластиковых карт. Все функции реализованы с упором на производительность и поддерживают работу с итерируемыми объектами.

## Описание функций

* *`filter_by_currency`* — фильтрует список транзакций по указанному коду валюты.


* *`transaction_descriptions`* — генератор, который поочередно возвращает описание (`description`) для каждой транзакции.

* *`card_number_generator`* — генератор номеров банковских карт в заданном диапазоне.

## Модуль `decorators`

Простой и гибкий декоратор для автоматического логирования работы функций

* **Логирование успешных вызовов**: фиксирует факт успешного выполнения функции

* **Логирование ошибок**: перехватывает исключения, записывает их тип и переданные аргументы

* **Сохранение метаданных**: благодаря `functools.wraps` декорируемые функции сохраняют свои оригинальные имена (`__name__`) и документацию (`__doc__`).

# Тестирование и проверка качества кода

В проекте настроено автоматическое тестирование с помощью `pytest`, проверка покрытия кода через `pytest-cov`


### Инструкции по запуску

Для проверки работоспособности проекта выполните соответствующие команды в терминале вашей виртуальной среды.

#### 1. Запуск юнит-тестов
Запускает все тесты в проекте, проверяет граничные случаи, маскировку карт/счетов, сортировку и фильтрацию данных:
```
pytest
```

#### 2. Проверка покрытия кода тестами
Выводит в терминал подробный отчет о том, какие строки кода были выполнены во время тестов, и подтверждает 100% покрытие модулей из папки `src`:
```
pytest --cov
```
